# Broccoli downloads

Broccoli is a native Mac launcher for macOS 26 and later, for Apple silicon and Intel Macs.
This repository hosts signed, notarized installers and release notes. Application source is maintained separately.

[Download releases](https://github.com/yednapg/broccoli-releases/releases)

- **Broccoli:** stable releases.
- **Broccoli Beta:** upcoming changes being tested.
- **Broccoli Dev:** frequent development builds.

Download the ZIP for your channel, unzip it, and drag the app into Applications.
Updates offered inside the app stay within that channel. Download and installation require your consent.

The `updates-public`, `updates-beta`, and `updates-dev` releases host channel feeds for the updater;
users should download the numbered app releases instead. Stable drafts are invisible until approved for publication.
